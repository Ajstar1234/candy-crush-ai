# Candy Crush AI

An AI-focused Candy Crush-style game environment built in Python.

## Project Overview

The goal of this project is to develop a functional match-three game environment and an AI agent capable of making decisions to complete objective-based levels under a limited number of moves.

Rather than simply recreating Candy Crush, the project is intended to explore how artificial intelligence can evaluate game states, select moves, and develop strategies for completing different level objectives.

## Current Features

- Object-oriented Python game architecture
- Randomized game board generation
- Horizontal and vertical match detection
- Match removal and board updating
- Initial implementation of special candies and power-ups
- Score and turn tracking

## Planned Features

- Player candy swapping and move validation
- Improved cascading and board regeneration
- Fully functioning special candies and power-ups
- Goal-based levels
- Limited-move level constraints
- Game-state representation for AI agents
- Automated move generation and evaluation
- AI agent capable of selecting moves
- Training and evaluation across multiple level types

## AI Goals

The long-term goal is to compare approaches for automatically playing goal-based match-three levels. The agent will need to consider factors such as:

- Available legal moves
- Immediate and future matches
- Special candy creation
- Remaining moves
- Level objectives
- Board-state changes after cascades

## Technologies

- Python
- Object-Oriented Programming
- Artificial Intelligence / Machine Learning *(planned)*
